# Análisis de Datos de Transporte (GTFS)

Proyecto de análisis de datos de transporte listo para Google Colab. Incluye estructura GTFS y visualización.

- Merge de datos
- Análisis de frecuencia de paradas
- Visualización
- Conclusiones
